# Ruby GoodJob 4.24 schema parity for Unreleased

## Participants

Andrei Makarov (@amkisko)

## Decisions

Additive migration `add_good_job_ruby_4_24_schema_parity` mirrors Ruby update migrations 16–22 at tag `v4.24.1`. Create migration and install template match the current Ruby install schema, including `lock_type` on `good_jobs` and `good_job_concurrency_claims`. Previously landed but unreleased Ruby 1795 / 1762 / 1749 items are listed under CHANGELOG Unreleased. `mix.exs` version stays `1.0.1` until a release is requested.

## Effects

Existing Elixir installs gain queue-scoped dequeue indexes, batch/executions indexes, cron index reorder, redundant index drops, and the claims table. Fresh installs get the full set from create/install. Claims schema module exists; claim grant/promote behavior is not in this pass.

## Next

Implement label-scoped concurrency and claims write path. Then `dequeue_query_sort`, `threads` naming, and skiplocked migration docs.
